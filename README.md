# ハッシュ値確認ツール

ベンダーから提供されたハッシュ値と、確認対象ファイルから算出したハッシュ値を比較するためのツールです。

Windows 環境での利用を想定し、PowerShell の `Get-FileHash` を使用します。
作業者が毎回コマンドでファイル名を指定しなくてもよいように、作業フォルダ内のファイルを自動検出して確認します。

---

## 対応ハッシュ方式

本ツールでは、以下の2種類に対応しています。

- MD5
- SHA256

ハッシュ方式ごとにスクリプトを分けています。

```text
Verify-MD5Hash.ps1
Verify-SHA256Hash.ps1
```

---

## ファイル構成

### MD5確認時

```text
hash_check_workspace/
├─ Run-MD5Check.bat
├─ Verify-MD5Hash.ps1
├─ vendor_hash.txt
└─ firmware.bin
```

### SHA256確認時

```text
hash_check_workspace/
├─ Run-SHA256Check.bat
├─ Verify-SHA256Hash.ps1
├─ vendor_hash.txt
└─ firmware.bin
```

`vendor_hash.txt` と `firmware.bin` は例です。  
ファイル名は任意ですが、作業フォルダ内の `.txt` ファイルと確認対象ファイルは、それぞれ1つだけにしてください。

---

## 使い方

### 1. 作業フォルダを用意する

任意の場所に作業フォルダを作成します。

例：

```text
hash_check_workspace
```

---

### 2. 必要ファイルを配置する

MD5確認の場合は、以下を同じフォルダ内に配置します。

```text
Run-MD5Check.bat
Verify-MD5Hash.ps1
ベンダー提供ハッシュ値を記載したtxtファイル
確認対象ファイル
```

SHA256確認の場合は、以下を同じフォルダ内に配置します。

```text
Run-SHA256Check.bat
Verify-SHA256Hash.ps1
ベンダー提供ハッシュ値を記載したtxtファイル
確認対象ファイル
```

---

### 3. ベンダー提供ハッシュ値をtxtファイルに記載する

ベンダーから提供されたハッシュ値を、txtファイルに貼り付けます。

#### MD5の場合

```text
d41d8cd98f00b204e9800998ecf8427e
```

#### SHA256の場合

```text
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```

#### 記載ルール

- ハッシュ値のみを1行で記載してください。
- 前後の空白は許容されます。
- 大文字・小文字は問いません。
- 空行は無視されます。
- 空行を除いて複数行ある場合はエラーになります。

---

### 4. batファイルを実行する

MD5確認の場合：

```text
Run-MD5Check.bat
```

SHA256確認の場合：

```text
Run-SHA256Check.bat
```

対象の `.bat` ファイルをダブルクリックして実行します。

---

## 自動検出仕様

本ツールは、PowerShellスクリプトが配置されているフォルダを作業フォルダとして扱います。

### ハッシュファイル

作業フォルダ内の `.txt` ファイルをハッシュファイルとして自動検出します。

| txtファイル数 | 動作 |
|---:|---|
| 0件 | エラー |
| 1件 | ハッシュファイルとして使用 |
| 2件以上 | エラー |

---

### 確認対象ファイル

作業フォルダ内のファイルから、以下の拡張子を除外したものを確認対象ファイルとして自動検出します。

```text
.ps1
.bat
.cmd
.txt
.log
```

| 確認対象ファイル候補数 | 動作 |
|---:|---|
| 0件 | エラー |
| 1件 | 確認対象ファイルとして使用 |
| 2件以上 | エラー |

---

## 出力例

### ハッシュ値が一致した場合

```text
[正常] ハッシュ値が一致しました。

作業フォルダ       : C:\hash_check_workspace
ハッシュ方式       : MD5
ハッシュファイル   : vendor_hash.txt
確認対象ファイル   : firmware.bin

ベンダー提供ハッシュ値 : d41d8cd98f00b204e9800998ecf8427e
算出ハッシュ値         : d41d8cd98f00b204e9800998ecf8427e

結果 : ファイルはベンダー提供ハッシュ値と一致しています。
```

---

### ハッシュ値が一致しない場合

```text
[警告] ハッシュ値が一致しません。

作業フォルダ       : C:\hash_check_workspace
ハッシュ方式       : MD5
ハッシュファイル   : vendor_hash.txt
確認対象ファイル   : firmware.bin

ベンダー提供ハッシュ値 : xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
算出ハッシュ値         : d41d8cd98f00b204e9800998ecf8427e

結果 : ファイルが破損している、または想定と異なる可能性があります。
確認 : ベンダー提供値、確認対象ファイル、ハッシュ方式を確認してください。
```

---

## エラーになる主なケース

以下の場合はエラーになります。

- `.txt` ファイルが存在しない
- `.txt` ファイルが複数存在する
- 確認対象ファイルが存在しない
- 確認対象ファイル候補が複数存在する
- ハッシュファイルが空である
- ハッシュ値が複数行記載されている
- ハッシュ値の文字数が不正である
- ハッシュ値に16進数以外の文字が含まれている
- 確認対象ファイルのハッシュ値算出に失敗した

---

## ハッシュ値の形式

### MD5

MD5は32文字の16進数である必要があります。

```text
d41d8cd98f00b204e9800998ecf8427e
```

### SHA256

SHA256は64文字の16進数である必要があります。

```text
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```

---

## 終了コード

| 終了コード | 意味 |
|---:|---|
| 0 | ハッシュ値が一致 |
| 1 | ハッシュ値が不一致 |
| 2 | 構成エラー・候補ファイル数エラー |
| 3 | ファイル読み取りエラー |
| 4 | ハッシュ値形式エラー |
| 5 | ハッシュ計算エラー、または想定外のエラー |

---

## 注意事項

- 作業フォルダ内には、ハッシュ値を記載した `.txt` ファイルを1つだけ配置してください。
- 作業フォルダ内には、確認対象ファイルを1つだけ配置してください。
- 複数のファイルを同時に確認する用途には対応していません。
- ハッシュ値が一致しない場合、対象ファイルの破損、取得ミス、改ざん、ハッシュ方式の選択ミスなどが考えられます。
- `.ps1` ファイルは、日本語表示の文字化け防止のため UTF-8 with BOM で保存することを推奨します。

---

## 推奨運用

1. ベンダーから提供されたハッシュ方式を確認する。
2. MD5の場合は `Run-MD5Check.bat` を使用する。
3. SHA256の場合は `Run-SHA256Check.bat` を使用する。
4. ベンダー提供ハッシュ値をtxtファイルに1行で貼り付ける。
5. 確認対象ファイルを同じフォルダに配置する。
6. batファイルをダブルクリックする。
7. `[正常] ハッシュ値が一致しました。` と表示されることを確認する。

---

## 補足

本ツールは、ファイルのハッシュ値を比較するための確認補助ツールです。  
ハッシュ値が一致した場合でも、ベンダー提供元の正当性や入手経路の安全性を保証するものではありません。
