## 短縮版本文

```markdown
HashChecker は、ベンダーから提供されたハッシュ値と確認対象ファイルから算出したハッシュ値を比較するためのツールです。

このプレリリースでは、業務制約に合わせた PowerShell 版に加えて、共通仕様に沿った Python / Go / C#/.NET / Rust 版の CLI 実装を追加しました。

## Highlights

- PowerShell 版を業務制約版として整理
- Python / Go / C#/.NET / Rust 版の CLI 実装を追加
- MD5 / SHA256 のハッシュ比較に対応
- ハッシュファイルと確認対象ファイルの自動検出に対応
- ハッシュ値の文字数、16進数形式、複数行入力を検証
- 言語間で終了コードを共通化
- `testdata` による正常系・異常系の確認ケースを追加
- GitHub Actions で個別テスト・ビルド・横断確認を実行

## Notes

このリリースは正式配布版ではなく、実装比較・学習・ポートフォリオ用途を主目的としたプレリリースです。

現時点では配布用バイナリやインストーラーは添付していません。各言語版を実行するには、必要に応じて Python、Go、.NET、Rust の実行環境または toolchain が必要です。
```
