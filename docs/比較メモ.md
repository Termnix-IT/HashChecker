# 多言語実装の用途と設計判断

同じ単体検証を複数言語で実装した比較基盤を保ち、各言語は異なる利用場面を担当します。この文書は、その分担と設計理由を説明します。操作は [手順書](HashChecker手順書.md)、契約は [共通仕様](../共通仕様.md)、ビルド・個別テストは言語別READMEを参照してください。

## 共通部分と独自機能の境界

ハッシュ値・一致判定・既存のCLI引数・終了コードは、共通CLIで揃えます。対応機能表示とバージョン付きJSONにより、利用者や呼び出し側が実装の対応範囲を確認できます。

一覧作成、GUI、集計まで全言語に複製すると、機能追加のたびに実装・テスト・手順を同時更新する負担が増えます。用途別機能は担当する実装で育て、一覧とJSONの形式を共有して連携します。仕様の共通化は、コードを言語間で一つのライブラリへ統合することを意味しません。

PowerShellはWindows標準機能と既存の`.bat`運用を優先します。共通CLIの引数名・JSON機能の実装は義務づけず、判定と記録の意味を合わせます。

## 用途別の実装判断

| 実装 | 実際に使っている機能 | 採用理由 | 維持する制約 |
|---|---|---|---|
| PowerShell | `Get-FileHash`、結果オブジェクト、`Export-Csv` | 追加の言語環境を入れず、既存のWindows作業と組み合わせる | Windows PowerShell 5.1とスクリプト配置による運用 |
| Python | `hashlib`、`argparse`、`json`、`csv`、`unittest` | 基準仕様を検証し、結果の検査・加工・集計を標準ライブラリで行う | スクリプト実行にはPython環境が必要 |
| Go | 標準ハッシュAPI、`encoding/json`、ファイルI/O | 利用者にGo環境を要求しないCLIをビルドし、CIで終了コードを扱う | 一覧にない追加ファイルは検査せず、一覧を順に処理する |
| C#/.NET | 共通Core、`IncrementalHash`、非同期I/O、WPF | 1つの検証処理をCLIと画面で再利用し、進捗・キャンセルを扱う | GUIはWindows専用。発行形式に応じてランタイムを用意する |
| Rust | `md-5`、`sha2`、`serde_json`、型付きエラー | フォルダ状態の記録と変更検出を、既存ハッシュ実装を用いて構成する | 一覧の保存先にhard link対応環境が必要 |

これらは、このプロジェクトの用途分担です。他言語で同じ機能を実装できないという意味ではありません。また、言語ごとの速度差は測定していないため、性能順位は設けません。

## 受け渡しの設計

Rustが作成したSHA256一覧をGoが検証し、そのJSON結果をPythonが集計します。C#とPowerShellは単体検証の操作・記録を担当し、他言語の実行ファイルを起動せずに使えます。

一覧はGNU形式の限定された範囲を採用し、未対応のエスケープ行を拒否します。パスを推測で補正せず、重複・フォルダ外参照・リンクを拒否することで、対象の解釈を揃えます。具体的な形式と終了条件は共通仕様が管理します。

JSONは検証結果の受け渡し、CSVは利用者向けの集計・記録に使います。JSON内の元のファイル名を保持し、CSVへの出力時だけ数式として解釈される文字列をテキスト化します。

Rustの一覧作成は、既存ファイルを上書きせず、書込み完了後に公開する設計を優先しました。標準ライブラリのhard linkを使うため、保存先のファイルシステムに制約があります。保存方式を変更する場合は、上書き防止と途中失敗時の扱いを維持する必要があります。

## 検証と保守

共通CLIは同じ固定データに対する終了コードに加え、JSONのハッシュ値・状態・件数を横断確認します。独自機能は言語別テストで確認し、Rust→Go→Pythonの連携を統合確認します。WindowsではPowerShellとWPF画面も確認します。

検証用`.bin`はバイト列を固定し、CLIのJSONとPythonの出力はUTF-8で扱います。これにより、WindowsとUbuntuで改行・文字コードによる差を避けます。具体的なコマンドとCI構成は [全体README](../README.md#開発時の検証)、固定データの目的は [testdata](../testdata/README.md) を参照してください。

将来機能を追加する際は、共通の判定・形式へ影響するかを先に確認します。利用者向けの操作、集計、配布形式だけの変更なら、担当する実装内で完結させます。
