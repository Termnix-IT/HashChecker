# 多言語版 比較メモ

このメモは、同じハッシュ確認ツールを複数言語で実装したときの違いを記録するためのものです。

## 実装順

1. Python
2. Go
3. C#/.NET
4. Rust

## Python

- 目的: 共通仕様を最初に固めるための基準実装
- 強み: 標準ライブラリだけでファイル I/O、CLI、ハッシュ計算、テストを書きやすい
- 見せどころ: 仕様分離、入力検証、終了コード、テスト容易性
- 注意点: 配布時は Python 実行環境、または exe 化の検討が必要

## Go

- 目的: 単一バイナリ配布と静的型付けの比較
- 強み: 配布しやすく、CLI ツールとの相性がよい
- 見せどころ: `crypto/md5`、`crypto/sha256`、明示的なエラー処理、クロスコンパイル

## C#/.NET

- 目的: Windows 業務ツール寄りの実装比較
- 強み: Windows 環境、GUI 化、配布形式との相性がよい
- 見せどころ: `System.Security.Cryptography`、CLI/GUI 展開、例外処理

## Rust

- 目的: 堅牢性、型安全性、配布性の比較
- 強み: 単一バイナリ、堅牢なエラー型、性能
- 見せどころ: 所有権、Result ベースのエラー処理、依存関係の選定
